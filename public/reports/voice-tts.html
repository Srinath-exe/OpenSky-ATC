Neural pilot voices that run in the browser

Pilot readbacks were spoken by the browser's one robotic voice, which is often missing in the phone app. Now they are made on the player's device by Paradee-8M v1.2, an 8.5 MB model distilled from Kokoro-82M: four voices, one per aircraft, with an ATC text normaliser in front and a VHF radio effect behind. On 60 real pilot lines it is as intelligible as its 82M-parameter teacher.

How a pilot line is spoken

The engine's line goes through four steps in the browser. Only the model and the runtime are downloaded; everything else is a few kilobytes of code.

  • ATC normaliser (src/lib/tts/pilotSpeech.ts): callsign codes become the engine's telephony (ICAO "fife, tree, niner" or FAA grouping, as phraseology.ts says them), FL350, runways (04L, 16R/34L), frequencies, altitudes, headings, squawks, units; fix names that read as words are said as words.
  • G2P (public/voice/tts-g2p.js): Paradee only heard misaki's phonemes in training, and misaki is Python. A 91 kB lexicon (27 kB compressed) holds misaki's own phonemes for the game's vocabulary in both accents (about 2,000 words), and the spoken names of the airspace fixes ("EPM" says "Epsom"). Unknown capitals are spelled with misaki's letter names; any other unknown word loads eSpeak NG (the phonemizer package kokoro-js uses, 0.7 MB compressed, only then) through paradee's eSpeak-to-misaki table.
  • Paradee (public/voice/tts-worker.js): one clause per call, in a module worker, so the first clause plays while the rest is made.
  • Radio (src/components/atc/pilotVoice.ts): two high-pass and two low-pass biquads (300–3400 Hz), a tanh soft clip and a light compressor, a faint hiss under the speech, a squelch click at the start and a squelch tail at the end.

Intelligibility on 60 real pilot lines

The lines are what the game speaks: readbacks, requests and status lines exported from the engine at six airports (KJFK, EGLL, KLAX, OMDB, YSSY, LFPG; 39 ICAO, 21 FAA), passed through the normaliser. Each clip was transcribed by Whisper base.en (faster-whisper, beam 5, no prompt) and scored against the words it was given; numbers count digit by digit whether written or spoken.

WASM ran about 3.8× slower than native onnxruntime on the same line and load. A profile puts 39 % of the time in convolutions and 15 % in the vocoder's sine, which WASM computes one value at a time. The fp32 file is about 1.3× faster in WASM but 35 MB instead of 8.5 MB, so the int8 file ships. WebGPU: the original int8 uses dynamic quantisation that WebGPU cannot run, and the WebGPU re-quantisation (danyalmalik/Paradee-8M-ONNX-WebGPU) is of v1.1, which has one voice.

The game's path: line to first sound

First clause audible, median (lines not queued)733 ms Lines spaced like traffic469 ms, 1187 ms, 552 ms Five lines at once2 dropped, the rest read faster

On top of the pilot's own reply delay (2–8 s). Long lines are cut at their commas into clauses of at least three words: the first is heard while the next is made. When lines pile up, at most two wait behind the one playing, the oldest waiting ones are dropped, a line that cannot start within 12 s is dropped, and lines with others ahead of them are read up to 24 % faster.

Audio8: a big model, for offline work

Audio8-TTS-Realistic-Air (Edge0, Apache-2.0) is a 0.6B-parameter DualAR model with a 44.1 kHz codec: 2.55 GB of weights, 23 languages including Hindi, and zero-shot voice cloning from a reference clip and its transcript. Its custom code was read before running: it only builds, loads and runs the model.

Seconds per readback (n = 5)504 s Audio per readback6.6 s Speed0.013× real time Codec decode share7 % Word error (Whisper base.en)4.5 %

Unusable live on a CPU, and far too big for the browser. On one data-centre GPU (L4 or A10 class, bf16, no CUDA graphs) a DualAR model of this size should run at roughly real time per stream, and much faster in aggregate with the SGLang Omni server's batching: an estimate, not measured here.

Why it is still interesting

  • Training data, offline. Speech-to-text needs varied voices saying ATC phrases. Audio8 can read thousands of lines overnight on a GPU, in many accents.
  • The owner's own voice. Cloning needs only a clean clip and its exact transcript. The owner's own recordings (the gold set) could seed a voice to read new controller lines for fine-tuning, with the owner's consent; nobody else's voice.
  • Hindi and other languages for accented-English variety.

In the game

  • Settings → Audio → Pilot voices: Neural (on this device, ~12 MB), the default, or Browser (speechSynthesis). Stored in skycontrol_pilot_voice.
  • Nothing downloads until the first pilot line. While the model loads, lines use the browser voice if there is one (the phone app's WebView often has none: there the first lines wait, up to two, and stale ones are dropped). If the model cannot load, the browser voice takes over for the session.
  • Each callsign keeps one of the four voices, a speaking rate of 1.00–1.14 and a pitch offset of ±70 cents, from a hash of the callsign; British airlines get the British voices, US airlines the American ones.

Method and caveats

  • Lines: ml/tts/lines.sh runs the headless engine in full-auto mode and keeps every pilot line it would speak, plus the readback the engine composes for each AI command, sampled command and template command; ml/tts/pick.py chooses 60 with one per phrase pattern (32 readbacks, 16 requests, 12 status lines).
  • Scoring: ml/tts/bench.py. Clips peak-normalised, 16 kHz. Reference = the normaliser's output. ICAO digits count as digits, spelled letters are joined, a few split names joined.
  • CPU: speeds were measured on a shared machine with other benchmarks running; compare them with each other, not with spec sheets.
  • Whisper base.en is itself a weak ATC listener ("Sky Dubai" → "sky to by" for every model, digit strings written as "1.5.3"), so the floor is not 0 %. With 60 lines, differences of a point or two between models are within noise.
  • The radio effect costs Whisper about 4–5 points (most on the male British voice), and a lighter version barely helps: the 300–3400 Hz band itself is what Whisper was not trained on. People hear radio speech every day; the game keeps the effect.
