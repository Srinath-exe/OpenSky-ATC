How it works: when you pick a situation, the model reads the game state into its KV cache (in the game this happens while you are still talking). Pressing Understand runs the same code as push-to-talk in the game: the transcript is repaired (ATC words, callsign matched by sound to the aircraft on frequency), the rules try it first, and only when they cannot parse it does the model write the command (first tokens restricted to callsigns that exist). A verifier then says the command back in words and compares it with what was heard: sure → sent; doubtful → left in the command bar to check; no matching aircraft → “say again”. Speaking uses the browser’s recogniser with its 5 best guesses. How we built it
