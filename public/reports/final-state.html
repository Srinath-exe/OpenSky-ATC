The chain

Microphone → speech to text → clean-up rules → the game's command parser → (if the rules fail) the command model → safety gate, which sends, asks the player to confirm, or asks "say again" → game engine → deterministic readback → pilot voice. The model only writes a typed command line; it never touches game state.

Known gaps

  • About 1 in 20 commands in casual wording is still sent wrong. More synthetic data gives less and less; the rest needs real players' speech (opt-in logging, spec 12).
  • The speech models were fine-tuned partly on UWB-ATCC and ATCOSIM, which have non-commercial licences. Fine for a showcase; a commercial release needs a retrain on the synthetic audio only (about $3 of GPU).
  • One of the owner's recordings is still missed ("Speedbird nine nine three two roger").
  • No on-device Parakeet in the browser yet; the browser uses the server.
  • SFO's real runway plan (depart 01L/01R) loses separation with AI on approach, so the default is 28L/28R.
