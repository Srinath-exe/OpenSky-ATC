Voice AI: plan and first results

Goal: talk to the traffic. The player holds push-to-talk and speaks like a controller. The command lands in the command bar where they can edit it, the aircraft does it, and the pilot reads it back. It runs in the browser, on phones and on cloud GPUs, and each part is built so you learn one AI-engineering skill doing it.

Architecture

From the player's voice to the pilot's readback

The model never writes game state. It produces the same command line a player would type. The engine checks it and applies it, then the pilot reads it back word for word, so any misunderstanding is heard straight away, like on a real frequency.

input

Push-to-talk

Hold a key or the on-screen button. Releasing it ends the utterance, so no end-of-speech wait.

STT

Streaming speech-to-text

Transcribes while you talk, primed with the callsigns, taxiways and fixes on frequency.

L0 · <1 ms

Rules

Normaliser plus the parser above. Takes clean phrasing.

L1 · the model

System-1 model

Game state plus transcript in, command line out. Handles messy speech.

editable

Command bar

Shows the command line with a confidence chip. You can edit it.

engine

Validate and apply

The same path as typed commands: frequency checks, scoring, replay.

phraseology

Readback text

Generated from the command itself. No model needed.

TTS

Pilot voice

One stable voice per aircraft plus a radio filter. The pilot's reply delay hides the generation time.

Confident and legal → execute.Unsure, two similar callsigns on frequency, or rejected by the engine → the pilot says "say again".Target: under 0.5% of commands executed wrong with high confidence.

Training data

The teacher talks mostly about headings

The rule-based AI is a free teacher: run the sim headless and every decision is a labelled (game state, command) pair. It is lopsided, though. Headings are 55% of everything it says, and it never issues holds, directs, go-arounds or conditional clearances. The dataset exporter adds a sampler that picks from each aircraft's currently valid actions, so the model sees every command kind.

Commercial or not?

Some public ATC speech sets (UWB-ATCC, for example) are non-commercial only. If OpenATC is commercial, they are used only for testing and the model trains on synthetic speech plus our own recordings.
